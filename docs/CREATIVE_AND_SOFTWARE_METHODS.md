# Creative production and software delivery methods

The reviewed, model-selected catalogue now has 146 methods. It loads entry text and
references only on explicit `read_skill`, under the existing shared context budget.
The added software method is original Braand guidance, not a coding execution
service. It differentiates proposed source, persisted commit, exact-revision CI,
provider deployment receipt and verified user journey. GitHub or hosting access
still depends on actual connected tools and the same server approvals.

The video direction reference now covers a complete production contract: editable
editorial sources, asset references, timeline, source-version-preserving revisions,
audio scope, independent aspect ratios and evidence of output quality. It does not
claim that prompt-based video, rush editing and programmed motion design are the
same operation. General-purpose code animation, free-form rendering and MP4 export
from arbitrary code remain unavailable without an isolated, costed renderer.

Four original document methods now use actual saved-report exports, rather than
incorrectly saying no exporter exists. Their guides retain limitations: no binary
Office editing, no spreadsheet calculation, text-only slides, and Latin-only PDF.
The six updated original methods have version 1.1.0 plus content digests. Upstream
MIT/Apache sources, user archives and their pinned manifests remain unchanged.

Validation uses the real catalogue compiler/provenance checks, registry/service
tests, model-selected multilingual discovery, source versioning, bounded progressive
reads and server-only build checks. The optional Python skill frontmatter checker
could not run locally because the bundled Python lacks PyYAML; this is separate
from the application's registry and CI validation. No live model, renderer, public
post, payment, new app account or software deployment in a customer's name is
created by reading these methods.

The supplied packs and their deduplicated Cloudflare storage are documented in [skill-packs.md](skill-packs.md). All distinct supplied methods and resources are retained; imported prompts remain references under the actual Braand runtime rules.
